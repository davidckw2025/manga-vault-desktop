# Manga Vault｜漫畫收藏 → Obsidian

Windows 本機漫畫收藏工具。輸入名稱、來源連結、封面與標籤，即可在自己的 Obsidian 筆記庫建立筆記、分類頁及總目錄。

目前版本：2.6。

## 使用

下載 Release 中的 `MangaVault.exe`，雙擊開啟。需要已安裝桌面版 Microsoft Edge 或 Google Chrome。

1. 選擇 Obsidian 筆記庫的根資料夾並授權。
2. 輸入漫畫名稱、來源網址、tag，拖入或貼上封面圖片。
3. 按儲存，在 Obsidian 開啟 `漫畫收藏工具/漫畫總目錄`。

也可直接用 Edge／Chrome 開啟 `index.html`。筆記庫位置會記在本機瀏覽器；重新開啟時會嘗試自動連接，必要時按「重新連接」授權。

## 功能

- 產生 Markdown 筆記、封面、分類連結與總目錄。
- 阻擋重複來源連結；支援編輯既有收藏。
- tag 按使用筆數排序，前 30 個常駐，其餘可展開。
- tag 輸入自動補全；可管理、新增、改名、合併或刪除標籤。
- 整頁拖放圖片與 Ctrl+V 貼圖，支援 PNG、JPEG、WebP、GIF，最大 20 MB。
- 只更新變動檔案；保存上一次資料及未完成儲存的恢復資訊。

## 資料與限制

收藏儲存在所選筆記庫的 `漫畫收藏工具` 子資料夾。不要手動編輯工具產生的檔案；請保留自己的筆記庫備份。避免多個視窗同時編輯。

一般收藏資料不會上傳至伺服器。拖入網頁圖片時，瀏覽器會向圖片來源發出讀取請求。部分網站會限制跨站讀取或使用不可分享的圖片網址；請改用「複製圖片」後 Ctrl+V，或使用本機圖片。

目前支援 Windows 與桌面 Edge／Chrome，EXE 是內嵌 HTML 的啟動器，介面由瀏覽器以獨立視窗顯示。清除瀏覽器資料或更換電腦後，需重新選擇筆記庫。

## 從原始碼建置

在 Windows PowerShell 執行：

```powershell
.\build.ps1
```

使用 Windows 內建 .NET Framework C# 編譯器，輸出 `dist/MangaVault.exe`。不需要 Node.js 或 Python。
